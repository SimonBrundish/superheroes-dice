# StrengthLab Superheroes Level Dice

Pick a year group, roll the dice, and get a random Superheroes level and exercise on a hero card.

- Year 1 = levels 1–4, Year 2 = 5–8 … Year 6 = 21–24, or All for 1–24.
- Link options: `?year=3`, `?year=all`, `?hero=hulk`, `&compact=1` (hides the title).

Embed on a page:

```html
<iframe src="https://simonbrundish.github.io/superheroes-dice/" title="Superheroes Level Dice" style="width:100%;height:1250px;border:0" allow="fullscreen" allowfullscreen></iframe>
```
